# Crash sounds

These short clips are selected at random by `bin/eternia-crash-watcher` when a
new native application core dump is recorded. The watcher is quiet unless the
active Omarchy theme is Eternia and rate-limits playback to one clip every 15
seconds.

The bundled clips were downloaded manually from the Voicy Skeletor soundboard:
https://www.voicy.network/official-soundboards/series/skeletor
